# 배포 준비 점검 — 2026.09.30

## 판단

퍼즐·교실 청소를 제외한 운영 프론트엔드를 점검했습니다. 확인된 목표·일정·계좌와 실제 폼 링크를 사용하며, 예시 실적·참여자·목업 안내는 공개 화면에서 제거했습니다. 기술 검증은 통과했지만 외부 폼의 사용처 안내를 페이지와 맞춘 뒤 공개하는 것이 필요합니다. 실제 Vercel 배포와 배포 도메인의 HTTPS 동작은 아직 확인하지 않았습니다.

## 구현과 검증

- `pnpm agent:verify`: doctor·전체 포맷·lint·타입 검사·프로덕션 빌드 통과. doctor는 과거 정적 HTML 배포가 아닌 Next.js 앱과 공개 자산을 검사합니다.
- `pnpm audit --prod`: 검사 시점에 알려진 취약점 0건. 모든 보안 위험이 없다는 보증은 아닙니다.
- Chromium: 375×812, 768×1024, 1440×900의 다섯 탭, 클릭·방향키·Home·End, 해시 직접 접근·복원, 본문 바로가기, 가로 넘침, 이동 버튼, 복사 성공·거부·미지원 상태를 확인했습니다.
- axe-core 4.13.0의 WCAG A/AA·2.1 검사: 세 화면 크기 × 다섯 탭에서 자동 검출 위반 0건. 작은 단계 번호의 대비를 보정했고 자동 검사가 접근성 전체를 보증하지는 않습니다.
- favicon과 SVG 아이콘을 추가했습니다. HTTP 응답에는 nosniff, 프레임 삽입 차단, referrer 정책을 적용하며 X-Powered-By는 제거했습니다.
- 확인된 금액·명단이 아직 없어 집계 준비 안내를 표시합니다. 0원이나 예시 명단을 실제 실적으로 표시하지 않습니다. 운영자 요청에 따라 명예의 전당 탭에 퍼즐·교실 청소·감사의 벽을 검토용 목업으로 표시합니다. 실제 실적과 연결하지 않으며 검토용 예시임을 안내합니다. 공개 전 최종안을 확정해야 합니다.

## 외부 폼에서 정리할 항목

[구글 폼](https://forms.gle/BYB5QtEWabs9sryR6)으로 2026.10.01 운영자 요청에 따라 주소를 변경했습니다. 아래 폼 점검 결과는 변경 전 주소에 대한 기록이며 새 폼에는 재확인이 필요합니다.

1. 페이지는 운영자 확인에 따라 ‘인증서 환경가치 조달에 전액 사용’을 유지합니다. 폼은 ‘인증서 구매 등 프로젝트 운영’이라고 안내하므로 폼의 문구를 맞춰야 합니다.
2. 폼에는 참여자 이름·학과의 공개 동의 항목이 없습니다. 현재 공개 명단은 없으며, 실제 내역을 공개하기 전에 동의를 수집할 방식이 필요합니다.
3. 이메일은 선택 입력입니다. 페이지에 인증서를 받으려면 이메일을 입력하라는 안내를 추가했습니다. 인증서 발급이 모든 참여자에게 필요한 운영이라면 폼에서 필수 입력으로 바꿀지 결정해야 합니다.

## 배포 설정

Vercel의 Root Directory는 저장소 루트, Framework Preset은 Next.js, 설치는 `pnpm install --frozen-lockfile`, 빌드는 `pnpm build`를 사용합니다. 참고용 `deployment/` 디렉터리를 배포하지 않습니다. 개발 확인 주소는 `http://localhost:3001`, 로컬 프로덕션 점검 주소는 `http://localhost:3002`입니다.

운영 도메인 `https://netzero-funding.vercel.app`을 canonical·공유 URL에 연결했습니다. 실제 배포 후 HTTPS에서 계좌 복사와 폼 이동을 다시 확인합니다. 공유 이미지는 아직 지정되지 않았으며 기본 제목·설명과 아이콘은 연결돼 있습니다.
