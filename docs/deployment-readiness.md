API 응답을 대체해 5분 갱신·중복 이름·목표 초과·명단 삭제·갱신 실패 시 정상값 유지·복구·첫 조회 실패 시 0원 오표시 방지를 검증했습니다. 실패 검증 중 HTTP 503 콘솔 메시지는 의도한 응답이며 페이지 실행 오류는 없었습니다. 빌드의 브라우저 자산에 서비스 계정 환경변수명·Google 토큰 및 Sheets API 주소가 포함되지 않는 것도 확인했습니다. 실제 서비스 계정 조회와 Vercel 배포는 미완료입니다.

## 배포 설정

Vercel의 Root Directory는 저장소 루트, Framework Preset은 Next.js, 설치는 `pnpm install --frozen-lockfile`, 빌드는 `pnpm build`를 사용합니다. 참고용 `deployment/` 디렉터리를 배포하지 않습니다. 개발 확인 주소는 `http://localhost:3001`, 로컬 프로덕션 점검 주소는 `http://localhost:3002`입니다.

운영 도메인 `https://netzero-funding.vercel.app`을 canonical·공유 URL에 연결했습니다. 실제 배포 후 HTTPS에서 계좌 복사와 폼 이동을 다시 확인합니다. 공유 이미지는 아직 지정되지 않았으며 기본 제목·설명과 아이콘은 연결돼 있습니다.
