# 배포 메타데이터

실제 제목·설명, canonical, Open Graph와 Twitter 설정은 [layout.tsx](../src/app/layout.tsx)를 기준으로 합니다. 운영 도메인은 `https://netzero-funding.vercel.app`이며 공유 이미지는 아직 연결하지 않았습니다. 확정된 이미지만 `openGraph.images`에 추가합니다.

## Gemini 공유 이미지 프롬프트

> 1200×630 웹 링크 미리보기 이미지. 대학 강의실에서 시작하는 재생에너지 참여를 단순한 그래픽으로 표현해줘. 진녹색(#234a3c)·연두색(#d7ed9f)·미색(#f5f6f2)을 사용하고, 실제 캠퍼스 사진·특정 건물·인물·로고·글자는 넣지 마. 왼쪽은 제목을 배치할 수 있게 비워줘.
