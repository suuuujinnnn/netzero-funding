# UI 검증

사용자에게 보이는 화면이나 동작을 바꿀 때 적용합니다. 브라우저 조작 흐름은 [Playwright CLI 스킬](../.agents/skills/playwright-cli/SKILL.md)을 참고합니다. 검증 도구와 명령은 프론트엔드 환경이 마련된 뒤 실제 설치된 도구에 맞춰 정합니다.

## 확인할 상태와 동작

- v4의 다섯 탭을 클릭과 키보드로 전환하고, URL 해시로 직접 접근했을 때 선택 상태를 확인합니다.
- 다음 단계 버튼과 계좌번호 복사 결과 메시지를 확인합니다.
- 데이터 연동이 생기면 관련 로딩·오류·빈 상태·성공 상태를 확인합니다.
- 375×812, 768×1024, 1440×900 안팎에서 가로 넘침, 잘림, 터치 영역, 긴 문단과 빈 공간을 확인합니다.
- heading 순서, 레이블, focus 표시, 이미지 대체 글, 명도 대비, 움직임 감소 설정을 확인합니다.
- 브라우저 콘솔 오류와 관련 네트워크 요청을 확인합니다. 스크린샷만으로 동작 검증을 대신하지 않습니다.

검증 환경이 막힌 경우 영향을 받은 화면과 동작, 원인, 대신 확인한 범위를 기록합니다. 확인하지 못한 동작을 통과했다고 보고하지 않습니다.
