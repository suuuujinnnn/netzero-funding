# UI 검증

화면이나 동작을 바꾸면 [Playwright CLI 스킬](../.agents/skills/playwright-cli/SKILL.md)에 따라 실제 브라우저에서 해당 범위를 확인합니다.

- 다섯 탭의 클릭·키보드 전환과 URL 해시 복원, 이동 버튼, 계좌 복사 결과를 확인합니다.
- 집계의 준비·정상·실패·복구 상태와 히어로·명예의 전당 값 일치를 확인합니다.
- 375×812, 768×1024, 1440×900에서 가로 넘침·잘림·터치 영역을 확인합니다.
- 접근성 이름·포커스·대체 글, 콘솔 오류와 관련 네트워크 요청을 확인합니다.

확인하지 못한 동작은 통과로 보고하지 않습니다.
