# 디자인 참고 자료 보관

`v4.html`, `v4.css`, `v4.js`는 프론트엔드 구현에 사용한 디자인 참고 원본입니다. `exports/`에는 v1~v4의 CSS·JavaScript와 이미지를 내장한 단일 HTML 기록을 보존합니다.

[이전 정적 HTML](../../deployment/index.html)은 v4 export의 홈 링크를 바꾼 참고 파일입니다. 운영 배포는 저장소 루트의 Next.js 앱을 사용하며 이 자료를 배포하지 않습니다.

자료 안의 수치와 안내는 당시 화면 검토용입니다. 현재 운영 정보는 프론트엔드 소스와 운영자의 확인 내용을 따릅니다.

## 명예의 전당 검토

v4의 기존 참여 내역 탭을 명예의 전당으로 바꾸고 1안 퍼즐·2안 교실 청소·3안 감사의 벽을 함께 배치했습니다. 같은 세 안을 실제 Next.js 화면의 명예의 전당 탭에서도 디자인 검토용 예시로 표시하며 실제 실적에는 연결하지 않습니다. 별도 목업 파일은 만들지 않습니다.

3안은 [DonorsWall](https://donorswall.com/)의 이름 전시와 [Watsi](https://watsi.org/)의 사람 중심 구성을 참고해 프로젝트 색상으로 재구성했습니다. 타 사이트의 이미지·코드는 가져오지 않았습니다. 금액 순위 대신 동일한 크기의 기념 카드와 가상 참여 메시지를 사용합니다.
