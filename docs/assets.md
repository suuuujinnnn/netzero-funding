# 이미지와 정적 자산

v4 목업은 사용자가 제공한 `assets/univ.jpg`를 히어로와 퍼즐에 사용하고, `assets/partners/*.png`를 관련 단체 이미지로 사용합니다. v4 단일 파일 export에는 두 종류의 이미지를 내장합니다. `docs/reference_v1.pdf`는 참고 자료이며 웹 화면 자산이 아닙니다.

프론트엔드를 만들 때 화면에 필요한 파일만 `public/` 아래로 옮기고 경로를 갱신합니다. 원본 파일을 임의로 삭제하거나 화질을 낮추지 않습니다. 큰 이미지의 크기와 실제 표시 크기를 확인한 뒤 필요한 경우 WebP 또는 AVIF로 최적화합니다.

- 히어로 사진에는 실제 보이는 장면을 설명하는 대체 글을 둡니다.
- 단체 이름이 옆에 텍스트로 있어 이미지가 장식 역할만 한다면 빈 대체 글을 사용합니다.
- 외부 로고와 이미지는 사용 출처와 공개 가능 여부를 확인합니다.
- Veily 전용 사진, 웨딩 아이콘, 색상 규칙은 이 프로젝트에 가져오지 않습니다.
