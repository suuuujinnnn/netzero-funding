# 비공개 구글 시트와 서버 연결

폼과 비공개 관리 파일은 연결했습니다. `설문지 응답 시트1`에 새 응답이 저장되며 `입금일`은 필수 날짜 질문입니다. 서버 코드의 `/api/funding`은 구현했으나 서비스 계정과 Vercel 환경변수 설정 전에는 실제 조회가 완료되지 않습니다. 시트나 탭을 웹에 게시하지 않습니다.

## 운영자가 하는 일

응답 탭 A:H는 타임스탬프·입금일·이름·신분·소속학과·기부금액·공개 동의·이메일입니다. I:L은 확인상태·확인금액·정정입금일·운영메모입니다.

1. 실제 입금과 대조합니다. 동일 입금에 중복 응답이 있다면 한 행만 확인 완료로 처리합니다.
2. J 확인금액에 실제 금액을 숫자로 입력합니다. 원본 기부금액 F는 보존하고, 날짜가 다르면 K 정정입금일을 입력합니다.
3. I를 `확인 완료`로 바꿉니다. 빈 상태는 대기입니다. 완료된 행의 금액 누락·문자·음수·소수는 집계 오류를 발생시킵니다.
4. 공개 동의가 `동의합니다` 하나만인 완료 건의 이름만 홈페이지에 전달합니다. 빈 동의·비동의·두 선택 동시 체크는 공개하지 않습니다. 별도 공개표시명은 받지 않습니다.

정렬은 원본과 확인값을 포함한 A:L 전체 행 단위로 수행합니다. 열만 따로 정렬하지 않습니다. 정정·상태 취소·전체 행 삭제는 다음 정상 조회에 반영됩니다. 이전 관리 템플릿은 숨겨 보존했으며 집계에 사용하지 않습니다.

## 서비스 계정 설정

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들거나 선택하고 Google Sheets API를 사용 설정합니다.
2. IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기에서 `netzero-sheet-reader`를 만듭니다. 프로젝트 역할과 도메인 전체 위임은 부여하지 않습니다.
3. 서비스 계정의 키 → 키 추가 → 새 키 만들기 → JSON을 선택합니다. 다운로드된 JSON을 채팅이나 저장소에 올리지 않습니다.
4. [관리 시트](https://docs.google.com/spreadsheets/d/1aAFvpV5t0_3YIngNYJspW6lffRnUx18n4YBeRjaMGgI/edit)의 공유 설정에서 JSON의 `client_email`을 **뷰어**로 추가합니다. 알림은 끄고 일반 액세스는 제한됨으로 유지합니다.
5. 로컬에서는 `.env.example`을 `.env.local`로 복사하고 아래 값을 직접 채웁니다. Vercel에서는 프로젝트 Settings → Environment Variables에 Production 범위로 동일한 값을 설정한 뒤 재배포합니다. Preview 접근이 필요할 때만 별도 범위에 추가합니다.

| 환경변수                             | 값                                               |
| ------------------------------------ | ------------------------------------------------ |
| `GOOGLE_FUNDING_SPREADSHEET_ID`      | `1aAFvpV5t0_3YIngNYJspW6lffRnUx18n4YBeRjaMGgI`   |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL`       | JSON의 `client_email`                            |
| `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` | JSON의 `private_key`, 실제 줄바꿈 또는 `\n` 허용 |

`NEXT_PUBLIC_` 접두사를 붙이지 않습니다. 이전 `NEXT_PUBLIC_FUNDING_CSV_URL`은 제거합니다. 로컬 서버는 환경변수 변경 후 재시작합니다. 서비스 계정의 뷰어 권한은 파일 전체에 적용되므로 원본 개인정보도 읽을 수 있습니다. 서버 코드는 집계 탭만 요청하지만 권한이 탭 단위로 제한되는 것은 아닙니다.

설정 방법 근거: [Google 서비스 계정 및 문서 공유](https://developers.google.com/workspace/guides/create-credentials), [서버 간 OAuth 인증](https://developers.google.com/identity/protocols/oauth2/service-account).

## 조회 계약과 오류

서버는 Google Sheets API의 `'홈페이지집계'!A1:C1001`만 읽습니다. 헤더는 `확인금액·확인건수·이름`, A2/B2는 숫자 집계이며 C열은 빈칸을 제외한 이름입니다. 순서와 중복 이름을 유지합니다. 1000건을 넘기기 전에 시트 수식과 서버 조회 범위를 함께 늘립니다.

`GET /api/funding`은 정상 시 `{ status: "ready", data: { amount, count, names }, checkedAt }`, 계정 미설정 시 `{ status: "unconfigured" }`를 반환합니다. 잘못된 설정·권한·인증·시트 데이터·네트워크 오류는 HTTP 503과 `{ status: "error" }`로 응답합니다. 비밀키·토큰·Google 원문 오류·원본 응답은 응답이나 로그에 넣지 않습니다. AI API와 Drive 커넥터는 운영 조회에 사용하지 않습니다.

브라우저는 첫 진입 및 5분 간격에 같은 도메인의 API를 조회합니다. 서버는 인스턴스별 정상 집계를 최대 60초 보관해 동시 요청을 줄이며, 마지막 조회 시각은 실제 Google 조회 성공 시각입니다. 갱신 실패 시 브라우저는 마지막 정상값을 유지합니다. 실패를 0원으로 처리하지 않습니다. 최초 미설정은 초기 0원으로 안내합니다. 설정 완료 후 최초 조회 실패는 금액 확인 중과 실패 안내를 표시합니다.

## 실제 연결 완료 기준

환경변수 설정 후 `/api/funding`에서 `ready`와 실제 초기 0원·0건을 확인합니다. 비식별 검증 응답 한 건을 운영자와 합의해 넣고 대기 제외 → 금액 입력·확인 완료 → 동의 이름 표시 → 정정·확인 취소 → 검증값 제거까지 확인합니다. 브라우저 네트워크에는 `/api/funding`과 집계 JSON만 보여야 합니다. Google 원본·인증키가 노출되면 완료로 보지 않습니다. 실제 Vercel 배포와 서비스 계정 생성은 별도 설정 작업입니다.
