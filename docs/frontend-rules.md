# 프론트엔드 구현 규칙

운영 화면은 `src/`, 시각 기준은 [DESIGN.md](../DESIGN.md), 디자인 참고 원본은 `docs/mockup/v4.html`입니다.

- 모바일부터 구성하고 375×812, 768×1024, 1440×900에서 가로 넘침·잘림·터치 영역을 확인합니다.
- 정적 내용은 서버 컴포넌트에 두고 탭·복사·집계 갱신처럼 브라우저 동작이 필요한 부분만 클라이언트로 둡니다.
- 지역 상태를 우선합니다. 새 전역 store나 API 추상화는 실제 공유 요구가 생길 때만 추가합니다.
- 화면 전용 스타일은 화면 가까이에 두고, 전역 CSS에는 토큰과 전역 규칙만 둡니다.
- TypeScript에서 `any`를 기본으로 쓰지 않고 외부 응답은 검증합니다. 파일명은 lowercase kebab-case, 컴포넌트 이름은 PascalCase를 사용합니다.
- 본문 바로가기, 의미 있는 제목 순서, 탭·패널 연결, 방향키·Home·End, 해시 복원과 포커스 표시를 유지합니다.
- 의미 있는 이미지에는 정확한 대체 글을 넣고 장식 이미지는 보조 기술에서 제외합니다. 상태·오류는 색상만으로 전달하지 않습니다.
